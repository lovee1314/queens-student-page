# Queen's Student Page

This repository contains Austin's personal Queen's School of Computing
student webpage.

## Live Website

https://lovee1314.github.io/queens-student-page/

## Files

- `index.html` contains the webpage content.
- `style.css` contains the page styling.
- `me.jpg` is the profile image.

## How to View

Open the live website using the link above. Alternatively, download the
repository and open `index.html` in a web browser.
